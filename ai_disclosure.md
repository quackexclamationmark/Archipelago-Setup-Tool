# ARCHIPELAGO SETUP TOOL - AI DISCLOSURE 

### AI was/is frequently used in the following cases:
- To build the main structure of the file downloader and some quality of life (QoL) features.
- I sometimes used AI for the front end of the tool.
- Explaining how all the code that was not written by me works.
- All game setup scripts are unique and sometimes very long, so they are usually altered by AI in some way, mainly for variables and config fields to save time without having to manually check all of them, all the time.

### AI was NOT used in the following cases:
- Research, ideas, most of the front end and testing are all entirely *made by/from* me (suggestions are usually from the Discord Server).
- The guides, tips, wikis, infos and the research behind them are **100%** written/made by me.
- All visual/art assets are made by me as well.

## Any code that the AI generated is highly reviewed and tested by me, and almost all case scenarios are covered.

**I am actively learning every day in the hope that one day I will only be using AI to save some time. I would say that I use AI as a learning tool, and this project is my sandbox where I'm giving it my all!**
